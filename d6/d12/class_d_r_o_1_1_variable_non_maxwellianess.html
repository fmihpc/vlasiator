DRO::VariableNonMaxwellianess::VariableNonMaxwellianess ( cuint popID)

Non-Maxwellianess Calculate for a population the relative entropy per density as defined by Cassak et al. *2023) as sigma_M = integral f log (f/f_M) d3v / n where f: measured VDF for a population f_M: a Maxwellian with same density n, flow speed U and three component temperature T No extra parameters need to be set in cfg file.
